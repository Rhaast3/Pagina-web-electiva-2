supportedFrameworks

La siguiente lista muestra algunos de los framewoks compatibles con vercel

  • Angular: ramework de desarrollo web creado por Google que permite construir aplicaciones de una sola página (SPA) de forma estructurada. Usa TypeScript como lenguaje principal, trabaja con componentes, data binding y servicios, y facilita la creación de interfaces dinámicas y escalables.
  • React: es una librería de JavaScript desarrollada por Facebook (Meta) para crear interfaces de usuario, esta basado en componentes reutilizables, ademas funciona muy bien para aplicaciones web dinámicas y escalables.
  • Next.js: Next.js es un framework de React que agrega renderizado en servidor, rutas automáticas y optimización para crear aplicaciones web rápidas y con buen SEO
  • Vue.js: es un framework progresivo de JavaScript diseñado para construir interfaces de usuario y aplicaciones web. Es llamado “progresivo” porque puedes usarlo poco a poco: desde añadir interactividad en una página sencilla hasta desarrollar aplicaciones completas.
