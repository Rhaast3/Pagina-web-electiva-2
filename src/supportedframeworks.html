Marcos en Vercel

Soporte de primera clase para frameworks frontend, backend y full-stack — despliega rápido, con previews por cada pull request.

Resumen

Vercel ofrece integración directa con una amplia variedad de marcos (frameworks) modernos: desde SvelteKit hasta Nitro y más. Puedes comenzar desde cero con Vercel o clonar uno de los repositorios de ejemplo en tu proveedor de Git e implementarlo usando una plantilla.

Cómo funcionan las implementaciones y previews

Las implementaciones de Vercel se integran con tu proveedor de Git para generar URL de vista previa por cada pull request que abras — ideal para revisiones y QA antes de fusionar a producción.

Principales características al usar marcos soportados

Funciones escalables

Escribe funciones que escalan según demanda, evitando caídas en horas pico y optimizando costos en baja actividad.

Middleware

Código que se ejecuta antes de procesar una solicitud, útil para personalizar respuestas y para operar antes de que la caché responda.

Soporte multi-runtime

Usa distintos tiempos de ejecución para tus funciones, escogiendo librerías y APIs según necesidades técnicas.

Regeneración estática incremental

Actualiza contenido sin redeploy: Vercel sirve la página desde caché y la reconstruye a intervalos configurados.

  • Perspectivas de velocidad: métricas de Core Web Vitals en el panel de Vercel para mejorar rendimiento.
  • Análisis: informes de rendimiento, páginas principales, referentes y demografía de usuarios.
  • Protección contra sesgos: bloqueo de versiones para alinear cliente y servidor y evitar errores de versión.

Create API de salida

La Create API de salida (Build Output API) es una especificación basada en sistema de archivos que define la estructura de directorios que produce una implementación de Vercel. Está pensada principalmente para autores de frameworks que desean integrar sus herramientas con las capacidades de la plataforma Vercel.

Al generar la carpeta .vercel/output como resultado del comando de compilación, los autores del framework pueden aprovechar funciones de plataforma como funciones serverless, enrutamiento y caché.

Si no usas un framework, aún puedes crear y completar manualmente .vercel/output siguiendo la especificación. Hay ejemplos en los repositorios oficiales de Vercel y una publicación de blog que detalla cómo crear tu propio framework con esta API.

Recursos y pasos rápidos

  1. Clona un ejemplo: git clone <repo-ejemplo>.
  2. Instala dependencias y corre tu build: npm install && npm run build.
  3. Desplega en Vercel desde tu proveedor de Git o usando vercel deploy.
  4. Revisa previews y funciones desde el dashboard de Vercel.

Comandos

  • vercel --prod — desplegar producción.
  • vercel dev — correr localmente con emulación de plataforma.

Consejos

  • Usa previews por pull request para QA rápido.
  • Configura rutas y caché en config.json de salida para controlar regeneración.
  • Revisa las guías oficiales y los ejemplos de Vercel para adaptaciones específicas de cada framework.
